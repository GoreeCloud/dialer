# GoreeCloud Dialer Branding

## Current verified state

The Android manifest identifies the application with the label **GoreeCloud Dialer**. It does not currently declare a repository-specific launcher icon, so no Dialer-specific icon provenance is accepted on this Development candidate.

## Requirements

- Preserve the product name **GoreeCloud Dialer**.
- Official product artwork must come from the approved GoreeCloud branding authority before a local derivative is treated as canonical.
- Local Android artwork is a packaging derivative only and does not become an independent branding authority.
- Do not reuse third-party dialer, carrier, OEM, generic telephone, or emoji artwork as official GoreeCloud identity.
- Stable product artwork must not encode runtime call state, carrier availability, or other operational state.
- Any future launcher icon or wordmark integration must record its canonical source and be validated before acceptance.

The missing accepted launcher-icon mapping is a Development branding gap; this record does not invent one.
