# GoreeCloud Dialer documentation

This directory is the canonical home for Dialer human-readable repository documentation. `README.md` remains the root entry point; machine-readable build, source-control, acceptance, and Platform Contract controls remain in their technically required locations.

## Canonical records

- `SPECIFICATIONS.md` — product and engineering requirements.
- `FEATURES.md` — current capability overview.
- `IMPLEMENTED-FEATURES.md` — implemented capability authority.
- `PLANNED-FEATURES.md` — planned, blocked, and incomplete capability authority.
- `CHANGELOGS.md` — repository-local changelog.
- `USER-MANUAL.md` — current user and operator behavior.
- `PRIVACY.md` — repository privacy guidance.
- `NOTES.md` — current development and maintenance notes.

## Supporting records

- `architecture.md` — Android/Telecom architecture.
- `physical-device-acceptance.md` — privacy-safe real-device/carrier acceptance procedure.
- `platform-modernization.md` — platform/toolchain modernization notes.
- `ci-validation.md` and `testing.md` — validation layers and evidence boundaries.
- `release-gates.md` — release qualification gates.

Security reporting and repository security guidance are maintained at `.github/SECURITY.md`.
